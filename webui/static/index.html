Hand

— ↗
Presets — sent as one J: line at the speed below (curl 0 = open, 1 = closed)
Fingers — by physical finger; drag to stream (the last line wins); abduction is the sideways spread, ±20°
firmware units, 50–2000; applies to the J: lines (presets and sliders)
Gestures — the firmware's own moves, one character each, at the hand's built-in speed
loading…
Raw line — exactly what the firmware reads: J:a0,…,a7,speed (servo offsets in degrees), a gesture character, or Q

          

          
Every command is one UDP datagram to port 8766, sent by the manager; on the hand's lossy WiFi a line can be lost, so repeat it if nothing moved. A running teleop panel or eval streams its own setpoints to the hand and overrides anything sent here.

Landmarks

          

            —
            
            
            
          

        

        

        
A landmark is where the robot stands when you add it: its x / y / yaw in the map frame, the map's name, the side and scene cameras stitched into one photo, and the RealSense frame. Go sends the robot there as a nav2 goal — the Map tab shows the drive and has HALT. Tasks tie a policy run (an eval) to the place: what you say, the model to serve, its instruction and how the run ends; “Robot Disco, pick up tigger” then drives to that landmark and runs it, and ▶ Run does the same from here. The entries live with the route editor on the robot (rd_ws/Scripts/landmarks/); the voice assistant reads the same file.
